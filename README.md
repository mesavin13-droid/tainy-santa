# Тайный Санта

Мобильный веб-сервис для корпоративной игры «Тайный Санта»: создание игры, вход без аккаунтов по ссылке/QR, закрытая жеребьёвка, пожелания, статусы подарков, анонимные вопросы и ответы.

## Текущий статус

- Главная страница и страница игры добавлены.
- Есть API для создания игры, присоединения участников, панели организатора, ограничений жеребьёвки, проведения жеребьёвки, личного кабинета и анонимных сообщений.
- Список участников на странице игры обновляется автоматически.
- SQL-миграции и тесты находятся в репозитории.
- CI запускает тесты, TypeScript-проверку и production build.
- Деплой пока не настроен: подключение проекта Vercel заблокировано правами текущего соединения. UI для загрузки видео-поздравления ещё нужно подключить к существующему API.

## Стек

- Next.js App Router + TypeScript + React
- Supabase PostgreSQL и Storage
- Vercel

## Переменные окружения

```dotenv
NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
SUPABASE_SERVICE_ROLE_KEY=YOUR_SERVER_ONLY_SERVICE_ROLE_KEY
```

`SUPABASE_SERVICE_ROLE_KEY` должна храниться только в секретных переменных окружения Vercel и никогда не иметь префикс `NEXT_PUBLIC_`. Не вставляйте этот ключ в клиентский код, GitHub или сообщения.

## Миграции

Применяйте SQL-файлы из `supabase/migrations` по порядку номеров. В Supabase уже подготовлена схема проекта и приватный bucket для видео-поздравлений.

## Локальная проверка

```bash
npm install
npm test
npm run typecheck
npm run build
```

CI: [GitHub Actions](https://github.com/mesavin13-droid/tainy-santa/actions).

## Проверка после деплоя

Откройте `/api/health`, затем протестируйте создание игры и жеребьёвку с 3–5 участниками. До проверки API и прав доступа не используйте сервис для реальной массовой игры.
