# Тайный Санта

Мобильный веб-сервис для корпоративной игры «Тайный Санта»: создание игры, вход без аккаунтов по ссылке/QR, закрытая жеребьёвка, wishlist, статусы подарков и анонимные вопросы с ответами.

## Статус
Исходный проект находится в архиве MVP v5. Репозиторий постепенно наполняется исходниками; пока приложение не развёрнуто.

## Стек
- Next.js App Router + TypeScript + React
- Supabase PostgreSQL и Storage
- Vercel

## Переменные окружения
```dotenv
NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
SUPABASE_SERVICE_ROLE_KEY=YOUR_SERVER_ONLY_SERVICE_ROLE_KEY
```
`SUPABASE_SERVICE_ROLE_KEY` должна храниться только на сервере в секретных переменных Vercel и никогда не иметь префикс `NEXT_PUBLIC_`.

## Миграции
Применяйте SQL-файлы из `supabase/migrations` по порядку номеров.

## Проверка после деплоя
Откройте `/api/health`, затем протестируйте создание игры и жеребьёвку с 3–5 участниками. Не запускайте массово до проверки API и прав доступа.

## Архив
Полная версия MVP v5 включает страницы, API-маршруты, миграции Supabase и тесты.
