# Тайный Санта

Мобильный веб-сервис для корпоративной игры «Тайный Санта»: создание игры, вход без аккаунтов по ссылке/QR, закрытая жеребьёвка, пожелания, статусы подарков, анонимные вопросы и ответы.

## Текущий статус

- Главная страница и страница игры добавлены.
- Есть API для создания игры, присоединения участников, панели организатора, ограничений жеребьёвки, проведения жеребьёвки, личного кабинета и анонимных сообщений.
- Список и количество участников (в том числе больше 12 человек) обновляются автоматически, а личный кабинет проверяет новые сообщения.
- Организатор может исправить настройки игры и исключить участника до жеребьёвки. Удаление защищено атомарной функцией в БД.
- SQL-миграции и тесты находятся в репозитории.
- CI запускает тесты, TypeScript-проверку и production build.
- Видео-кружки и видео-поздравления **убраны** из интерфейса и серверного API. Старый маршрут отвечает `410 Gone`; прежние файлы не удаляются автоматически.
- Онлайн-проверка пока заблокирована: проект Supabase `tainy-santa` приостановлен из-за лимита активных бесплатных проектов. Доступ к развёртываниям Vercel в текущем соединении ограничен.

## Стек

- Next.js App Router + TypeScript + React
- Supabase PostgreSQL
- Vercel

## Переменные окружения

```dotenv
NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
SUPABASE_SERVICE_ROLE_KEY=YOUR_SERVER_ONLY_SERVICE_ROLE_KEY
```

`SUPABASE_SERVICE_ROLE_KEY` должна храниться только в секретных переменных окружения Vercel и никогда не иметь префикс `NEXT_PUBLIC_`. Не вставляйте этот ключ в клиентский код, GitHub или сообщения.

## Миграции

Применяйте миграции из `supabase/migrations` по порядку номеров. Новая `0006_atomic_participant_removal.sql` обязательна **до** использования кнопки удаления участника: она защищает от гонки между удалением и жеребьёвкой. Миграции `0004`–`0005` исторические (отключённый видео-модуль); при существующей базе их не удаляйте из истории миграций. Не публикуйте серверный секретный ключ.

## Локальная проверка

```bash
npm install
npm test
npm run typecheck
npm run build
```

CI: [GitHub Actions](https://github.com/mesavin13-droid/tainy-santa/actions).

## Проверка после деплоя

Откройте `/api/health`, затем протестируйте создание игры и жеребьёвку с 3–5 участниками. До проверки API и прав доступа не используйте сервис для реальной массовой игры.
